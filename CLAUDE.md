# Fens League

HTML/CSS prototype of the "Фенска Лига" lobby from the Figma file "Last Fan"
(https://www.figma.com/design/OrPsoRJGjW7r90HuKMFl7b/Last-Fan?node-id=238-6770), frame "1.0 - Lobby Main" (238:6770), designed for a **375px phone**. The page stretches to any width; desktop isn't designed or optimised yet, mobile is the focus. Since 2026-11-10 this is the only lobby: the older "Главно Лоби" page (frame 178:40236, hand-placed layout, intro drafts) was removed at the user's request and lives only in git history (before commit "Make the new lobby the only one").

## Where things live

- `components/tab-nav.js`: the floating bottom tab bar (Figma 299:9412) shared by all pages. Its markup is copied into each page with that page's tab marked `is-active`; tabs with a real page link to it, the others are `#` for now. Switching pages slides the pill from the old tab, and the next page opens only once that slide has finished. The five icons are Figma's exports (`assets/lobby-main/nav-*.svg`) written into each page as inline `<svg>`, so they are drawn with the bar's first frame; as `<img>` they arrived a moment after it on every page change.
- `components/page-motion.js`: moving between the product's pages, the ball slides off to the right and the left text block (title, subtitle; on the lobby also the league / "Как се играе?" row) slides off to the left; the next page slides them back in, so the ball video restarting happens off screen. The tab bar waits for the slide-out before opening the page. The content under the top section goes with it (2026-11-13): leaving, it fades out and drops 8px; arriving, it's hidden (`arrive-pending`) until the slide starts, then rises in block by block (the lobby's panel and cards; on Прогнози the panel, tab row, then its lists via `window.pageArriveStart`). Прогнози's tabs (График, Отбори, История) animate their content on opening; switching rounds (Следващ / Текущ) has no animation (user's request). The gold counters on Прогнози/Класиране start once their subtitle has finished coming in.
- `components/ball-video.js`: loads the ball video (each page's `<video>` names its files in `data-src-mov` / `data-src-webm`, no `<source>`) as a whole file into memory and starts it at a random point; it fades in once there. Done this way because seeking needs HTTP range support, which neither the hosting nor `serve.py` has.
- `components/page-boot.js` (in every page's `<head>`): decides whether the intro plays. Only when you come into the product from outside (another site such as the main Sport/Casino pages, a bookmark, a typed address, a new tab): the previous page (`document.referrer`) isn't on this site. Moving between the product's own pages (tab bar, header "Fens League", logo, back/forward, reloads of such pages) shows the page straight away. When the intro will play, it hides the top section until it starts. The lobby's ball is nudged 3px down so it sits where the other pages have it (y 113).
- Page transitions (view transitions, the ball and title morphing between pages) were tried on 2026-11-11 and reverted at the user's request: they flickered (white flashes, the ball video turning into a white box). Hosting and `serve.py` don't answer HTTP range requests, so the ball video can't be seeked.
- `HANDOFF.md`: where the last session stopped.
- `RULES.md`: the rules of the game from the user (points, teams, power cards, ranking, all 16 achievements with their texts). Any copy that states a rule follows it; the Правила page is built from it.
- Git: branch `main`, remote `origin` = private GitHub repo `jpavlov96-pixel/fens-league` (SSH).
- Hosting: Cloudflare Worker with static assets, https://fens-league.j-pavlov96.workers.dev/, deployed from GitHub on every push to `main`, so **a push is a public deploy**: push only when the user asks. `.assetsignore` keeps the notes and dev files off the site.
- Tab "Fens League" (renamed from Figma's "Fen League" by the user) replays the intro on every tap (`replayIntro()`).
- Changes the user made on purpose against Figma: crests keep their shape, centred in their 114×68 slot (Figma stretches them; changed at the user's request 2026-11-13, they had been stretched until then), EGT logo 72×30 (Figma 48×20), "Месец" filter removed, "Как се играе?" has a moving white highlight on a 6% white border, no blue tap flash. The bottom tab bar has no background blur and a 97% tint (Figma: blur 10, 87%): the blur made the bar blink on page changes in Samsung Internet (2026-11-12).

## How to run it
- Start the server from this folder: `python3 serve.py`, run with Bash in the background. It's `http.server` on port 8420 with caching turned off; plain `http.server` let browsers keep old copies of `styles.css`. A server launched from `.claude/launch.json` can't read ~/Documents, so that entry only attaches to the URL.
- Preview: http://localhost:8420/. A phone on the same Wi-Fi can use `http://<Mac IP>:8420/` (get the IP with `ipconfig getifaddr en0`).

## Working rules (from the user)
- Take every value and asset from Figma through the Figma connector. **Never estimate** from screenshots.
- **No variables** of any kind (no CSS custom properties, no Figma variable binding) until the user says so.
- **Reload the preview** after every change the user can see.
- **Don't publish** anything (claude.ai links or otherwise) unless the user asks again.
- Build only what's asked, section by section, and **re-read the Figma structure first**, because it changes between sessions.
- **The ball's bounce intro (`introBounceRefined()`) must always be included**: every lobby page or rebuilt screen that has the ball gets it, with the ball as the video (it needs `playbackRate` for the spin kicks), the tap-to-skip and the replay on the "Fens League" tab. Since 2026-11-11 (user's request) it plays only when entering the product from outside; see `components/page-boot.js`.
- Figma's generated code carries variable *fallback* colours (e.g. a blue gradient, mint button) that aren't what Figma shows; take colours from `get_variable_defs` on the frame instead.
- EGT Digital branding: the user is OK with it showing on the hosted site (2026-11-10), including the logo on the ball video and the header logo `assets/lobby-main/egt-digital-logo.svg`, which is in git and on the live site. claude.ai copies still swap the logo for a "LOGO" placeholder.
